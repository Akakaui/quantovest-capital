# Capability Matrix

| Capability | Available | Required | Decision |
|---|---:|---:|---|
| Web browsing | Yes | Yes | Used to inspect reference and license pages |
| Controlled screenshots | Yes | Yes | Used at desktop, tablet, and mobile viewports |
| Web/image research | Yes | Yes | Used to evaluate real phone mockup sources |
| Image generation | Available | No | Not used because the user requested a real sourced asset |
| Video generation | Available | No | Not required for this hero pass |
| 3D model creation | Available | No | Not required after selecting a real phone mockup asset |
| Asset storage | Local GitHub repository | Yes | Asset stored in `public/assets/` for the original repo |
| Visual review | Yes | Yes | Screenshots inspected after each major visual repair |

The selected phone source is a commercial-license mockup provider. Personal-use-only sources were rejected. The current repository asset is an externally sourced transparent PNG with a deterministic background cleanup; the device itself is not generated or procedurally drawn.
