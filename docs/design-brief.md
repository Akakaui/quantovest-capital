# Design Brief

## Audience and roles

The product serves prospective investors, authenticated investors managing deposits and copy-trades, and staff operating the admin console. The primary conversion event is starting an account; the primary investor task is understanding balance and strategy activity; the primary admin task is reviewing platform queues and user state.

## Experience goals

The public site should communicate institutional confidence without pretending to be a regulated guarantee. The investor portal should make capital, risk, ROI, KYC, deposits, and withdrawals easy to scan. The admin console should feel clearly privileged and operationally separate from investor navigation.

## Visual direction

The selected direction is Editorial Signal: near-black canvases, signal green as the single positive/action color, restrained rules, mono financial metadata, asymmetric layouts, and real device imagery rather than procedural mockups.

## Success criteria

The site must retain existing copy and routes, preserve all feature interactions, avoid color collisions across public/investor/admin contexts, avoid horizontal overflow below 400px, keep CTAs accessible, and present a sourced real phone asset in the hero across desktop, tablet, and mobile.
