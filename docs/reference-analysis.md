# Reference Analysis

## Observed visual principles

The supplied direction favors a nearly black canvas, a high-contrast two-line headline, a green emphasis line, a compact eyebrow, pill CTAs, a right-side angled phone visual, and a slim market ticker below the first screen. The phone is a focal device rather than a full interactive dashboard.

## Reinterpreted principles

Quantovest keeps its existing copy and routes but adopts the hierarchy, asymmetry, signal green, divider rhythm, phone annotation, and mobile cropped-device behavior. The device is now an external real mockup asset with a transparent background, not a CSS-drawn phone body.

## Explicit non-copy constraints

Do not copy external site code, logos, protected images, proprietary brand identity, or exact DOM/CSS. Use the supplied visual only as a composition reference. Keep existing Quantovest content and feature behavior unchanged.

## QA hypotheses

The highest-risk responsive issue is phone overlap at widths below 400px. The highest-risk consistency issue is a light card or sidebar entering the dark investor/admin workspace. The highest-risk asset issue is a visible matte or low-resolution phone image, so the asset is inspected and the white background is removed deterministically before use.
