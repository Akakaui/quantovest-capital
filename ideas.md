# Art Direction Decision

## Direction A — Editorial Signal (selected)

Near-black canvas, signal green, mono financial metadata, asymmetric copy/device split, real angled phone asset, and restrained motion. This reinforces institutional confidence while keeping the platform’s finance purpose legible.

## Direction B — Bright Fintech Utility

White canvas, blue accent, dense data cards, and a conventional SaaS dashboard language. Rejected because it weakens the existing Quantovest premium dark operational identity.

## Direction C — Cinematic Neon Trading

Black canvas, large gradients, animated charts, and heavier glow. Rejected because it risks hype, reduces readability, and can imply performance promises.

The selected direction uses the supplied reference only for composition principles. It does not copy external code, logos, or protected imagery.
